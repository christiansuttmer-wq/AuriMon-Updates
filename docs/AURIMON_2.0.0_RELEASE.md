# AuriMon 2.0.0 — Neuer Start und Originalgrafiken

- Original AuriMon Fantasy-Kristallwelt als Start-Hintergrund.
- Neues gold-/eisblaues AuriMon-Logo auf der Startseite.
- Neues goldenes Kristall-A als Android-Launcher-Icon in 5 Android-Auflösungen.
- Eine freundliche Begrüßungsnachricht für alle Trainerinnen und Trainer direkt im Startmenü.
- **Achtung: Alle alten lokalen Spielstände, sechs Profile und Sicherungen werden beim ersten Start unwiderruflich gelöscht.** Dies geschieht ausschließlich beim ersten Öffnen von v2.0.0; danach werden alle neuen Spielstände erhalten.
- Keine externen Nachrichten versendet: der Gruß erscheint in der App auf jedem Gerät.
- 1.025 Pokémon, 40 Regionen, 200 Ebenen und bestehende Spielmechaniken bleiben verfügbar.
- Grafik aus Original-Generierung: Stand 23.10.2026.

## Abnahme
Die 2.0.0 ist erst freigegeben, wenn Reset-, Asset-, Browser- und signierter Android-Build bestanden wurden.
